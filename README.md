# Auto Film Experts

A modern React-based website for Auto Film Experts, specializing in automotive protection services including Paint Protection Film (PPF), ceramic coating, vinyl wrapping, and more.

## 🚀 Features

- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Smooth Animations**: GSAP-powered transitions and effects
- **Dynamic Routing**: Service pages loaded dynamically
- **SEO Optimized**: Structured for search engine visibility
- **Fast Performance**: Vite build system for optimal loading

## 🛠️ Tech Stack

- **Frontend**: React 18 with Vite
- **Styling**: Tailwind CSS + Styled Components
- **Routing**: React Router DOM
- **Animations**: GSAP
- **Forms**: React Hook Form
- **Typography**: Adobe Fonts (Typekit)

## 📁 Project Structure

```
src/
├── components/          # Reusable UI components
│   ├── service/         # Individual service pages
│   └── ...
├── hooks/               # Custom React hooks
├── pages/               # Full page components
└── App.jsx              # Main application
```

## 🚀 Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

### Preview
```bash
npm run preview
```
